🎮 Tic-Tac-Toe Game Using Python & NumPy

📌 Project Overview

This project is a console-based Tic-Tac-Toe game developed using Python and the NumPy library. It allows two players to play against each other on a 3×3 game board, taking turns placing their symbols (X and O).

The game automatically checks for winning combinations across rows, columns, and diagonals. It also identifies draw situations when all cells are occupied without a winner.

This project demonstrates the practical application of Python programming concepts, conditional logic, loops, functions, exception handling, and NumPy array operations.

🚀 Features

* Two-Player Gameplay: Supports two players (X and O).
* Interactive Game Board: Displays a clean 3×3 Tic-Tac-Toe board.
* NumPy Integration: Uses NumPy arrays to manage and update the game board.
* Win Detection: Automatically checks rows, columns, and diagonals for winning combinations.
* Draw Detection: Identifies when the game ends without a winner.
* Input Validation: Prevents invalid entries and out-of-range positions.
* Occupied Cell Protection: Prevents players from selecting an already occupied cell.
* Error Handling: Uses exception handling to manage invalid user inputs.

🎮 How to Play

1. The game starts with an empty 3×3 board.
2. Player X makes the first move.
3. Player O takes the next turn.
4. Enter the row and column numbers (0, 1, or 2) to select a position.
5. The game checks for a winner after every move.
6. The first player to align three symbols horizontally, vertically, or diagonally wins.
7. If all cells are occupied without a winner, the game ends in a draw.
